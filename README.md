📝Text Editor Demo

- Clone repository: git clone https://github.com/tvtoan/text-editor.git

- Di chuyển sang thư mục : text-editor
- Cài đặt bằng npm: npm i
- Chạy dự án: npm run dev

UI demo
- Tiptap
+ URL: http://localhost:3000/tiptap
+ File nguồn: app/[locale]/tiptap
- SunEditor
+ URL: http://localhost:3000/sunEditor
+ File nguồn: app/[locale]/sunEditor
- SlateJS
+ URL: http://localhost:3000/slateJS
+ File nguồn: app/[locale]/slateJS
- CKEditor
+ URL: http://localhost:3000/ckeditor/post
